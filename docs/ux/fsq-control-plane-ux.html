Run contract

dynamic
01
Pre-plan first

FSQ derives key actions and one final verification goal before external UI actions.

02
Execute through harness

All platform actions route through FSQ capability metadata and StepRunner.

03
Collect evidence per step

Screenshots and normalized UI snapshots attach to the run timeline.

04
Verify from evidence

Final status comes from the verifier, not the execution agent's self-report.

05
Generate replay asset

Successful replayable actions become strict YAML for deterministic replay.

06
Attach to workspace

Generated cases can be saved back into the active coding directory for future strict replay and PR review.
